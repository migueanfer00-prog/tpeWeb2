**TEMATICA:**

Son panaderías que poseen productos a la venta.



**DESCRIPCION:**

Cada panadería tendrá su id\_panaderia(como PK), nombre, fecha de Fundación,

horario de apertura y cierre, dueño, dirección y teléfono.

Cada producto tendrá su propio id\_producto(como PK), nombre, precio unidad,

precio docena y id\_panaderia(como FK).
